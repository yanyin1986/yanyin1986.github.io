# Git

## 概览
Git 是当前开发工作流中的核心版本控制工具。在这批导入笔记里，它主要与 SSH 身份隔离、多账号协作以及仓库 remote 管理相关。

## 在当前 wiki 中的关注点
- 一机多账号时，重点不是 Git 配置本身，而是 SSH Host 与密钥映射。
- clone、fetch、push 使用的 remote 地址会直接决定命中的 SSH 身份。
